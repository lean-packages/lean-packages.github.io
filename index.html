GUIDING PRINCIPLES

Why lean distribution matters

Published packages are consumed thousands or millions of times. Unintentional files waste bandwidth, slow down CI, and reveal internal repository structure.

Smaller distribution archives

Minimizes archive payload size, reducing download latency and disk consumption across CI runners, server deployments, and local development environments worldwide.

Explicit package exclusions

Prevents accidental leakage of test suites, mock data, private CI credentials, IDE settings, and internal documentation into public registry mirrors.

Language-native tooling

No alien configuration formats or heavy runtime wrappers. Every tool works directly with your ecosystem’s native manifests and package manager standards.

Open-source & community-driven

Transparent, permissively licensed (MIT), and built collaboratively by developers who care about sustainable, efficient software distribution.

Tools & Utilities

Explore the specialized packages available across the lean-packages ecosystem.

PHP v0.9.2
lean-packages/php-lean

php-lean

A library and CLI tool for validating and managing .gitattributes export-ignore rules to ensure development-only files do not get packaged in published Composer distribution archives.

composer require --dev stolt/php-lean
Rust v0.4.2
lean-packages/cargo-lean

cargo-lean

A Cargo subcommand for validating, auditing, and optimizing Cargo.toml package exclusion lists to prevent unnecessary files from inflating crates.io distribution tarballs.

cargo install cargo-lean
Python v0.2.5
lean-packages/py-lean

py-lean

A Python tool for detecting, configuring, and fixing missing source-exclude patterns in pyproject.toml to ensure repository-only files are omitted from source distributions.

uv tool install py-lean-package
JavaScript v0.1.1
lean-packages/js-lean

js-lean

A CLI tool for validating and optimizing lean JavaScript & TypeScript package distribution by checking package.json files allowlists and .npmignore files.

npm install -D js-lean

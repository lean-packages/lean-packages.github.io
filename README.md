# lean-packages.github.io

Official website and landing page for the **lean-packages** GitHub organization ([https://github.com/lean-packages](https://github.com/lean-packages) | [/dev/null](https://dev-null.sh/@lean-packages)).

## About

`lean-packages` is a collection of open-source developer tools helping software authors ship leaner distribution archives across multiple programming languages (PHP, Rust, Python, Ruby, JavaScript/TypeScript, Zig).

## Ecosystem Projects

- **[php-lean](https://github.com/lean-packages/php-lean)** — Validates and manages `.gitattributes` `export-ignore` rules for Composer packages.
- **[cargo-lean](https://github.com/lean-packages/cargo-lean)** — Validates and manages `Cargo.toml` `[package].exclude` lists for Rust crates.
- **[py-lean](https://github.com/lean-packages/py-lean)** — Detects and fixes missing `source-exclude` patterns in `pyproject.toml` for Python packages.
- **[ruby-lean](https://github.com/lean-packages/ruby-lean)** — Audits `.gemspec` declared file lists and validates `.gem` archives for Ruby gems.
- **[js-lean](https://github.com/lean-packages/js-lean)** — Audits and enforces lean packaging rules (`package.json` `files` and `.npmignore`) for npm packages.
- **[zig-lean](https://github.com/lean-packages/zig-lean)** — Audits and optimizes `build.zig.zon` `.paths` allowlists for Zig packages.
- **[action](https://github.com/lean-packages/action)** — Unified GitHub Action for automated lean package linting across all ecosystems.

## Tech Stack & Architecture

- Semantic HTML5 & CSS3
- Vanilla JavaScript for GitHub API version fetching & clipboard interactions
- Dark-first developer aesthetic with zero third-party framework overhead
- Hosted directly via GitHub Pages
